# Product Plan

## Goal
Build a browser-based guitar and bass tab editor.

## Initial users
- Guitarists and bassists who want to sketch riffs, songs, and practice material.
- Users who want a simple clickable fretboard rather than typing ASCII tab.

## Core workflow
1. Choose instrument and tuning.
2. Click frets to insert notes or chords.
3. Arrange events into bars and beats.
4. Set tempo using tap tempo.
5. Preview the sequence with simple synthesized playback.
6. Save and reload songs locally.

## Later features
- Chord dictionary and chord insertion.
- Technique annotations: hammer-ons, pull-offs, slides, bends, vibrato, palm mutes.
- MIDI file export.
- Standard music notation using abcjs or VexFlow.
- Import/export of songs as JSON.
